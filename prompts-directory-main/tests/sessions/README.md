# User test sessions

**Human-only** acceptance specs. One file per session before agents implement.

## How to

1. Duplicate [TEMPLATE.md](./TEMPLATE.md) → `TS-YYYYMMDD-feature-name.md`
2. Fill every section; use fake secrets only
3. Log the file in [../test.md](../test.md) TEST_LOG with `impl_status: pending`
4. Start a **new** Cursor chat for implementation (Prompt A or custom) and point to your `TS-*.md`

Agents must not delete or overwrite your session files without explicit instruction.
