# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please **do not** open a public issue for exploitable security bugs in NoVibeLeaks itself.

Use [GitHub private security advisories](https://github.com/Procoder1234556/NoVibeLeaks/security/advisories/new) or contact the maintainers through GitHub.

We aim to acknowledge reports within a few business days.

## Scope

- NoVibeLeaks MCP server, Python library, and official workflows in this repository.
- Upstream `vendor/` trees are governed by their own projects; report issues there when appropriate.
